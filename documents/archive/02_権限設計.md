# 権限設計書

## 権限体系

FY Nexus One ではロールベースアクセス制御（RBAC）を採用する。

### ADMIN

システム管理者権限

利用可能機能

- 法人設定
- ユーザー管理
- ユーザー招待
- 権限設定
- 監査ログ
- マスタ管理
- 全職員閲覧
- 全施設閲覧

### HR_MANAGER

人事担当者権限

利用可能機能

- 職員管理
- 雇用条件書管理
- 有給管理
- 資格管理
- 退職管理
- 証明書発行

制限事項

- システム設定変更不可

### MANAGER

部署責任者権限

利用可能機能

- 自部署職員閲覧
- 承認処理
- 申請確認

制限事項

- 他部署閲覧不可
- システム設定変更不可

### USER

一般職員

利用可能機能

- マイページ
- 各種申請
- 雇用条件書確認
- 資格確認
- 扶養申請
- プロフィール変更

制限事項

- 他職員情報閲覧不可
